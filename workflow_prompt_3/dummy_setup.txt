THE ONE THING THAT CANNOT BE FAKED, READ THIS FIRST

Slack, Gmail, Jira and GitHub stamp their own timestamps and none of them can be backdated. Everything seeded today will carry today's real date, not the scenario date.

So every seeded Slack message, every seeded email body and every pull request title opens with its scenario date in square brackets, like [2026-07-02], and that bracketed date is the real date for the purposes of this scenario. Write it exactly that way every time. Jira descriptions carry a line reading Scenario date: YYYY-MM-DD instead.

Do not skip these date prefixes. Without them the master run has no dates to reason about and half the scenario collapses.
