Everything the master workflow reads or writes has to exist and be named exactly as written here, otherwise that run will fail partway through.

This is a SETUP RUN ONLY.

Do not create outreach.

OUTREACH RULES TAB

Columns: Rule, Value, Notes

Rows:

Cold Outreach Hold Period
90 days
Do not create another cold outreach draft if equivalent outreach went out in the previous 90 days, unless a new and verified opportunity signal has appeared. For a run dated 2026-08-31 this puts the cutoff at 2026-06-02, so mail sent on or after that date holds the prospect.

Drafts Per Run
2
A run creates at most 2 Gmail drafts even when 3 prospects qualify. The 2 highest Opportunity Scores take the slots, ties broken by the count of evidence items carrying source URLs, remaining ties broken by Company Name A to Z. The prospect that misses out is set to Draft Deferred with a Next Action Date and a written reason.

Draft Only
Yes
The workflow creates Gmail drafts only. It must never send an email automatically.

Duplicate Draft Check
Required
Search existing Gmail drafts and relevant conversations before creating another draft.

Manual Notes Protection
Required
Never overwrite BDE Notes entered by a human.

Future Contact Request
Respect
If a prospect asked to be contacted on a specific future date (time zone: Asia/Kolkata), do not contact them before that date.

Previously Declined
Hold
If a prospect declined earlier and no meaningful new evidence justifies re-engagement, do not create another cold email.

Existing Customer
Hold
Do not treat an existing customer as a new cold prospect.

Outcome Guarantees
Prohibited
Outreach must never guarantee rankings, traffic, revenue, leads, conversions or any other business outcome.


PROSPECTING RULES TAB

Columns: Rule, Value

Rows:

Prospects Per Run
3

Queue Order
Last Audit Date ascending, an empty Last Audit Date counts as older than any filled one, ties broken by ClickUp task creation date ascending, remaining ties broken by Company Name A to Z

Eligibility
Research Status is Pending, Website URL is present, and the task has not already been completed for the current review cycle

Review Cycle Format
Monthly, recorded as YYYY-MM (time zone: Asia/Kolkata), for example 2026-08

Prospect Type
B2B companies that could reasonably need software development, website development, mobile development, custom software, AI or automation, UI and UX, or dedicated engineering resources

Allowed Sources
Google Search, company websites, public company pages, public press and news pages, public company registries

Excluded Sources
Any site requiring a login, including LinkedIn, Apollo, Upwork and Freelancer

Excluded
Existing customers, obvious competitors to our own IT services business, companies without a verifiable website, duplicate companies, companies with insufficient public evidence

Minimum Evidence
At least 3 recorded evidence items each carrying a source URL, drawn from at least 2 of the 4 inputs, being the website audit, the PageSpeed run, the search observations and the competitor comparison

Minimum Website Findings
3 separate observable findings per prospect, each with its own source URL

Non-Branded Queries Per Prospect
Exactly 3

Organic Results Reviewed
Top 20, ads and sponsored placements ignored

Brand Search Alone
Not sufficient

Missing Website URL

No Forced Opportunity
Yes

A company is not qualified simply because it has a website.
